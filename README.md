# 🌦 WeatherInsight — интерактивная визуализация метеоданных
Приложение на Streamlit для анализа и визуализации исторических метеорологических данных из базы weather.db.
Подходит для аналитиков, студентов и метеорологов, которым нужно быстро исследовать погодные показатели, сравнивать города и строить временные ряды с прогнозом.

### 📝 Описание
WeatherInsight позволяет:

- загружать данные из SQLite‑базы 'weather.db' ;

- фильтровать данные по диапазону дат и городам;

- просматривать таблицу с обработанными и производными признаками;

- автоматически вычислять:

-категорию температуры (холодно / умеренно / жарко);

-уровень осадков (без осадков / небольшие / сильные);

-индекс комфортности (на основе температуры и ветра);

- выполнять EDA‑анализ:

📊 гистограммы;

📦 boxplot‑диаграммы;

- сравнивать города по средним значениям показателей;

- строить временные ряды и прогнозировать значения с помощью скользящего среднего.



### Используемые библиотеки:

pandas — обработка данных

numpy — расчёты

sqlite3 — подключение к базе

plotly.express — интерактивные графики

streamlit — веб‑интерфейс

### ⚙️ Установка зависимостей
Убедитесь, что установлен Python 3.9+.

1. Клонируйте репозиторий:

Код
`git clone https://github.com/USERNAME/WeatherInsight.git`
`cd WeatherInsight`

2. Создайте виртуальное окружение (по желанию):

Код
`python -m venv venv`

Активация окружения:

Код
`venv\Scripts\activate      # Windows`

`source venv/bin/activate   # Linux/Mac`

3. Установите зависимости:

Код
`pip install streamlit pandas numpy plotly`

Убедитесь, что файл weather.db находится в корне проекта.

### 🚀 Запуск приложения
Запустите приложение командой:

Код

`streamlit run app.py`

После запуска приложение откроется в браузере.
Если не открылось автоматически, перейдите по адресу:

Код

`http://localhost:8501`
